# Fiches pense-bêtes

Des aide-mémoire à garder ouverts à côté de l'IDE pendant les TP. Chaque fiche couvre un thème
sur plusieurs TP. Le badge `TP N` de chaque section indique le TP où la notion apparaît :
ignorez ce qui dépasse votre TP actuel.
Chaque fiche a une section ⌨️ IntelliJ pour son thème ; la liste générale (avec macOS) est dans la fiche 10.

| Fiche | Thème | Utile à partir du |
|---|---|---|
| [1 — Beans et injection de dépendances](01-beans-ioc.md) | annotations, injection par constructeur, graphe des beans de troc-api, erreurs au démarrage | TP 1 |
| [2 — HTTP et REST](02-http-rest.md) | verbes, chemins, codes de statut, annotations de contrôleur | TP 2 |
| [3 — Configuration](03-configuration.md) | `application.properties`, sources et priorités, `@ConfigurationProperties`, profils | TP 3 |
| [4 — DTO, validation, erreurs](04-dto-validation-erreurs.md) | objets de requête, records, enums, `@Valid`, `@RestControllerAdvice` | TP 4 |
| [5 — Persistance et transactions](05-persistance-transactions.md) | Spring Data JDBC, `schema.sql`, console H2, `@Transactional` | TP 5 |
| [6 — AOP](06-aop.md) | proxy, aspect, advice, pointcut, logger | TP 7 |
| [7 — Tests](07-tests.md) | JUnit, Mockito, MockMvc, base de test | TP 8 |
| [8 — Sécurité](08-securite.md) | `401` / `403`, mots de passe, JWT, `SecurityFilterChain` | TP 9 |
| [9 — Outils et dépannage](09-outils-depannage.md) | mvnw, Java, Bruno, console H2, Swagger UI, diagnostic par code | tous |
